# Cloud PC

A private Linux desktop in your browser: https://45.77.105.187/vortex/cloudpc/

- Sign in with RedX and accept the Terms. Each desktop: 2 vCPU, 3 GB RAM, 5 GB personal storage, isolated sandbox.
- **Requests**: new users request access; the owner approves or denies (and can revoke) from the Owner Panel.
- Rules: no illegal content, no attacks, mining or abuse of other systems; desktops may be reset or removed for violations
  (see [TERMS.md](TERMS.md)).
- Background agents can run on your Cloud PC once access is approved.
