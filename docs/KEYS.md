# API keys

Create keys under **Library, Merges & Keys → API Keys**. Each `redx_ai_…` key has a name, allowed models,
requests per minute, usage counts, last-used time and a **Revoke** button. The full key is shown **once**;
the server stores only a hash. Use it as `Authorization: Bearer <key>` with `https://ai.red-xai.com/v1`.
Never paste keys into chats, issues or screenshots. Outside provider keys are sealed server-side.
