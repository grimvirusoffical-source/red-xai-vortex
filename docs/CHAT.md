# Chat

- **New chat**: ⌘N (macOS) or **+ New chat**. Each chat keeps its own history locally.
- **Model picker**: choose any installed model; `vortex` is the default. Display names
  (Vortex Lite 3B, Vortex 8B, Vortex 24B, Vortex MoE 8x7B …) map to the underlying model files.
- **Agent picker** (desktop): chat through an agent, including agents that use an external provider and your own API key.
- Attach files, use voice, plugins, skills and MCP tools — see [CHAT-FEATURES.md](CHAT-FEATURES.md).
- **Group chat** lets several models answer the same prompt side by side.
